# UPS 守护

通过 NUT 服务器监测 UPS，在负载超限时降低本机功耗，并在电池不足时按规则休眠的 Windows 托盘应用。

[English](README.md) · [下载版本](https://github.com/kylefu8/ups-guardian/releases) · [更新记录](CHANGELOG.md)

## 当前状态

当前为 **Windows 测试版**，在 Windows 11 x64 上验证了监测与界面。规则、恢复和更新使用模拟测试验证。实际限功耗、恢复及休眠需要在自己的电脑上安排受控测试，不能把模拟测试视作硬件兼容性保证。

macOS 留待下一阶段。本版已整理可复用的通讯、规则、语言资源和平台接口，但没有提供 Mac 程序，也不承诺 Mac 支持 Windows 式显卡瓦数限制或休眠。

## 使用

1. 从 Releases 下载 Windows ZIP，解压后运行 `UPSGuardian.exe`，保留同目录的 `UPSGuardian.Updater.exe`。
2. 在「连接设置」点击「搜索局域网」，从结果中选择一台 UPS，再点击「确认并连接所选 UPS」。没有可读取的结果或尚未确认时，不开始监测，也不能启用保护。默认扫描 NUT 3493 端口，可调整扫描端口；服务器需允许本机执行只读 `LIST UPS` 和 `LIST VAR` 查询。
3. 确认成功后先只读监测，再到「保护策略」确认功率口径、阈值和本机限制。新配置按负载百分比设置阈值，不假设其他 UPS 的额定瓦数。
4. 确认硬件能力并验证限制与恢复后，以管理员身份打开，再手动启用自动保护。
5. 关闭窗口会收起到系统托盘。「暂停并恢复限制」停止自动动作；「退出」恢复本程序拥有的限制后结束进程。

程序会记住唯一确认目标，下次启动先验证同一目标，可读取才恢复监测；失败时回到发现页面，不会自动选择其他 UPS。每次启动后，自动保护都需要手动开启。旧配置的地址和保护参数会保留，但首次使用发现功能仍需确认目标。

发现优先扫描带网关的活动以太网/Wi-Fi IPv4 接口；没有此类接口时才使用其他活动以太网/Wi-Fi 接口。较大的网段只扫描本机所在 `/24`，最多 1024 个地址、16 个并发探测、30 秒总时限，可随时取消；实际范围会显示在界面上。未找到设备时，请检查范围、端口与 NUT 客户端白名单。IPv6 和跨网段发现暂不支持。

界面支持简体中文、英语、日语、韩语、法语、德语和西班牙语，切换语言不重启监测。「使用说明」「版本更新」「支持开发」均可从左侧一级菜单直接打开；使用说明详细介绍连接、阈值、权限、休眠、托盘操作与常见故障。

侧栏下方的地球图标可打开语言菜单，显示当前选择并支持跟随系统；旁边常驻显示当前版本，点击版本号可进入更新页面。

## 关键规则

- 超阈值持续 5 秒后降低本机功耗；回落到「阈值 − 回差」以下并持续 30 秒后恢复原设置。
- GPU 目标为 `0` 表示只限制 CPU。正值必须落在运行时检测范围内；不会提高用户已有的更严格限制。
- **只有电池供电时**，电量低于 50% 或续航低于 180 秒，才按默认的 5 秒确认与 20 秒倒计时准备休眠。
- 来电、条件解除、数据失效或手动暂停会取消待执行休眠。
- 休眠尽量保留 Windows 会话，不等于每个应用都保存了文件；计算任务仍需要自己的 checkpoint。
- UPS 总负载包括其上所有设备。没有实测瓦数时，仅在负载率和额定瓦数都存在的情况下估算；不能将其当作本机精确功率。

## 在线更新

在左侧「版本更新」中可检查 GitHub、下载并安装新版本。安装前需暂停保护并恢复已有功耗限制。更新程序等待主程序退出，重新校验 SHA-256，只替换允许的发行文件；失败时回滚，本地 `data/` 不被覆盖。

版本号统一定义在 `version.json`。测试版可以发现预发布版本，稳定版忽略预发布版本。当前测试版尚无代码签名。
