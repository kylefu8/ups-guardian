# UPS Guardian 0.1.0-beta.5

## 中文

### 主要变化

- 新增 Windows 用户级安装包，默认安装到 `%LOCALAPPDATA%\Programs\UPS Guardian`。
- 安装时可创建开始菜单项，也可选择创建桌面快捷方式。
- 继续提供便携 ZIP；应用内更新仍使用 ZIP 包。
- 安装包覆盖到同一目录时保留该目录的 `data/`；卸载时也保留 `data/`。
- 发布中英文双语说明，并补充打包与安装包验证边界。

### 安装与升级

需要安装时使用 `UPSGuardian-0.1.0-beta.5-windows-x64-setup.exe`；需要便携运行时解压 `UPSGuardian-0.1.0-beta.5-windows-x64.zip`。安装包覆盖到同一目录会保留 `data/` 中的设置、事件、语言选择和待恢复记录。安装到不同目录不会自动迁移旧目录的 `data/`。

应用内检查和安装更新时下载的是 ZIP。执行应用内更新前，请先暂停保护并等待程序恢复它拥有的限制；更新程序会等待主程序退出，安装完成后自动重启。直接运行安装包或卸载程序前，还应从系统托盘退出。若启用了登录自启，请先在应用内关闭并保存，再进行卸载。检测到 `recovery.xml` 时，安装和卸载会被阻止，必须先让应用完成恢复，避免遗留程序拥有的功耗限制。卸载会保留 `data/`，便于备份或在确认后手动清理。

## English

### Highlights

- Add a user-level Windows installer, defaulting to `%LOCALAPPDATA%\Programs\UPS Guardian`.
- Offer a Start Menu entry and an optional desktop shortcut during setup.
- Keep the portable ZIP distribution and use ZIP packages for the application's built-in update flow.
- Preserve the installation's `data/` folder when an installer upgrade targets the same directory, and leave `data/` in place when the application is uninstalled.
- Publish bilingual release notes and document the packaging and installer validation boundary.

### Installation and upgrade

Use `UPSGuardian-0.1.0-beta.5-windows-x64-setup.exe` for a per-user installation, or extract `UPSGuardian-0.1.0-beta.5-windows-x64.zip` for a portable installation. A same-directory installer upgrade keeps settings, events, language preference and any recovery record in `data/`. Installing to a different directory does not migrate the old `data/` automatically.

The application checks and installs updates from the ZIP package. For an in-app update, pause protection and let the application restore limits it owns; the updater waits for the application to exit and restarts it after installation. Before running the installer or uninstaller directly, also exit from the system tray. If login-at-startup is enabled, turn it off in the application and save before uninstalling. If `recovery.xml` is present, installation and uninstall are blocked until the application completes recovery, so owned power limits are not left behind. Uninstalling leaves `data/` available for backup or deliberate cleanup.

### Validation and limits

Validation covers simulated application and update behavior plus an independent installer sandbox. The release does not claim hardware certification, code signing, or notarization. Actual CPU/GPU power changes and hibernation still require controlled validation on the target Windows system.
