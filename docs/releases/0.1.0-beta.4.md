# UPS Guardian 0.1.0-beta.4

## 中文

### 主要变化

- 保护页突出负载、电池电量和续航三个阈值；CPU/GPU 限制、恢复回差和时间设置收进「高级设置」，摘要显示保存的配置值。
- 确认 UPS 后显示紧凑的设备卡片。「更换 UPS」只展开发现控件，不会自动搜索、替换目标或改变保护状态。
- 概览合并设备信息、隐藏常规提示；负载曲线可按需展开，收起后仍继续保留已采集的样本。

### 升级说明

已有 UPS 选择和保护参数会保留。高负载触发 CPU/GPU 降功耗与后续恢复能力继续可用，启动后保护仍需手动开启。旧配置如果还没有确认目标，需要先完成发现并明确确认，之后才开始监测。

本版本 Windows x64 发行物为便携 ZIP。请让 `UPSGuardian.exe` 和 `UPSGuardian.Updater.exe` 保持在同一目录，并确保安装目录中的 `data/` 可写。

### 验证范围与限制

本版本检查了模拟的规则、语言、发现和更新行为，进行了隔离的 WinForms 生命周期检查，并查看了本地界面。这些检查不代表实际 CPU/GPU 限功耗、休眠、特定 UPS 型号或显卡驱动配置已经获得认证。

## English

### Highlights

- Protection now foregrounds load, battery-charge and runtime thresholds. CPU/GPU limits, recovery margin and timing details are grouped under Advanced settings while their saved configuration values remain visible in the summary.
- A confirmed UPS is represented by a compact device card. Opening Change UPS only reveals the discovery controls; it does not scan, replace the target or change protection state.
- The overview combines device information, suppresses routine notices and lets the load chart be expanded when needed without discarding collected samples.

### Upgrade notes

Existing UPS selection and protection parameters are retained. The load-triggered CPU/GPU reduction and restoration behavior remains available, and protection still requires manual activation after startup. A previously unconfirmed legacy profile must complete discovery and explicit confirmation before monitoring starts.

The Windows x64 distribution for this release is the portable ZIP package. Keep `UPSGuardian.exe` and `UPSGuardian.Updater.exe` together, and keep the installation's `data/` folder writable.

### Validation and limits

The release was checked with simulated policy, localization, discovery and update behavior, isolated WinForms lifecycle checks, and local interface inspection. These checks do not certify actual CPU/GPU power changes, hibernation, a particular UPS model, or a graphics-driver configuration.
