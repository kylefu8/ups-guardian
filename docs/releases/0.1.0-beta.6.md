# UPS Guardian 0.1.0-beta.6

## 中文

- 修复分辨率降低或可用屏幕区域变小时，窗口右侧和底部内容被裁切、无法操作的问题。
- 窗口支持拖动边框调整大小和最大化。空间不足时，页面可横向、纵向滚动，侧栏可独立滚动到语言、版本和退出入口。
- 使用说明的阅读区跟随窗口变化；更新页、支持页和高级设置中的底部按钮均可通过滚动访问。
- 首次显示、屏幕区域变化和从托盘重新打开时，普通窗口会调整到当前屏幕可见范围。

在应用的「版本更新」中下载并安装即可；已有配置会保留。也可下载 Windows x64 安装包或便携 ZIP。安装前按提示暂停保护并恢复已有的功耗限制。

验证：115 项模拟检查、现有 WinForms 界面测试，以及新增的原生缩放边框、七页面按钮可达性、中英德文、150% 缩放几何、屏幕区域变化消息回归；检查了真实窗口的渲染图。实际切换显示分辨率和鼠标拖动尚未完成实测。未执行真实功耗限制或休眠操作。

## English

- Fix inaccessible content at the right and bottom of the window after the available display area becomes smaller.
- Enable window resizing and maximizing. Smaller pages expose horizontal and vertical scrolling, while the sidebar scrolls independently to its language, version and exit controls.
- Resize the guide's reading area with the window and keep update, support and advanced-settings actions reachable by scrolling.
- Fit normal windows into the current screen's working area on first show, display/work-area changes and reopening from the tray.

Use **Updates → Download and install** to upgrade while preserving settings. The Windows x64 installer and portable ZIP remain available. Pause protection and restore owned power limits when prompted before installation.

Validation: 115 simulated checks, existing WinForms suites, and new native resize-border, seven-page action-reachability, Chinese/English/German, 150% scaled-geometry and display-message regression checks. Rendered images of shown windows were inspected. A live display-resolution switch and physical mouse drag have not been tested. No actual power-limit or hibernation actions were invoked.
